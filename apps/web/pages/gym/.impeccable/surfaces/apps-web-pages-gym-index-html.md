# Demo interactiva de gimnasio

- Alcance: reemplazo completo de `apps/web/pages/gym/index.html`.
- Modo: Persuade mediante una experiencia operable.
- Audiencia: propietarios y responsables comerciales de gimnasios que evalúan una web a medida.
- Trabajo del visitante: construir una sesión, explorar clases, zonas y entrenadores, simular una
  reserva y abrir una conversación de cotización con Luenio.
- Contenido y prueba: toda la información del club es ficticia e ilustrativa; la interacción es la
  prueba del tipo de experiencia que Luenio puede construir.
- Restricciones: sin métricas, clientes, precios, resultados o disponibilidad presentados como
  reales. Mantener “Demo ficticia creada por Luenio”.
- Dirección: Class Board, combinación B+C. Constructor dominante con itinerario diario, panel de
  clases, banda fotográfica, entrenadores y señalización split-flap.
- Momento memorable: objetivo + nivel + horario transforman el panel y producen una ruta antes de
  reservar.
- Pendiente: reemplazar nombres, horarios, fotografías y lógica demostrativa por los datos reales
  del futuro cliente.
