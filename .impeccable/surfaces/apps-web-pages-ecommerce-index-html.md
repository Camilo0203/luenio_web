# Demo de ecommerce

- Scope / mode: landing ficticia de tienda tecnológica; persuadir ayudando a elegir.
- Audience: compradores que comparan tecnología premium antes de decidir.
- Job: declarar un uso, recibir una recomendación ilustrativa y continuar al catálogo.
- Action: conocer el producto recomendado; secundaria, explorar productos.
- Proof/content: recomendador, catálogo, beneficios y soporte; precios y productos se mantienen demostrativos.
- Direction: mesa de producto azul hielo, superficies blancas y señal amarilla.
- Memorable moment: el producto protagonista cambia según el uso seleccionado.
- Constraints: español, responsive, WCAG AA, compra real y disponibilidad no simuladas como operativas.
